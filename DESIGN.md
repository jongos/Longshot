# Longshot Website Design

Voice: an independent field report, skeptical but constructive. The defining move is the juxtaposition of a large imperative headline with a concrete annotated evidence sheet. Restraint: no mascots, Marvel artwork, fake dashboards, simulated test counters or autonomous-product claims.

Considered directions: dark inspection console; theatrical comic-panel sequence; editorial field report. Selected the field report for readable evidence and a human-scale counterpoint to the companions. The asymmetric paper sheet, ruled findings and step sequence carry the subject. Color alone is not the distinction.

Typography: local Archivo variable font, exported using Dazzler's font helper with OFL notice. Body 17px/1.6, maximum prose measure 60ch; headline tightly set; code uses system monospace. Headings use English Title Case. No motion except optional smooth anchors, disabled for reduced motion.

Semantic colors: paper #f5f1e8, ink #20231e, action/accent #a33512, secondary field #344638, inset #fffdf7, muted #55594f. Dazzler color generator explored a warm mineral seed #BA3D12; final custom surface relationships are measured separately. Orange denotes review emphasis, not a destructive action. No destructive controls exist.

Structure: proposition and illustrative finding; method; task use cases; bounded loops; report anatomy; install/invoke; companion roles; sourced namesake; limitations. Native links and semantic HTML, no JavaScript dependency. Small-screen layouts linearize the same content and reading order.

Content boundary: claims concern skill instructions and documented synthetic validation. No human outcome, complete accessibility, model reliability, directory acceptance or paid-service guarantee is implied. Comics exposition is a personal tribute with source links, not Marvel affiliation.
