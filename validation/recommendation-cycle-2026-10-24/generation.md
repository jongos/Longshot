# Generation record

Independent agents received the frozen skill and its references, only their six development packets or four fresh packets, a common task, and (for candidates) their one added instruction. They used the same inherited agent model; there were no model overrides. Each condition ran in a separate context with no surrounding conversation. No generator received expected answers, another report, evaluator results or selection rationale. Each condition's cases shared a context, so cases are not statistically independent samples.

Common task: concise recommendation-quality review of each packet only; supported findings or working behavior, evidence limits, recommendation if warranted, and a falsifiable acceptance check. Maximum 160 words per case; no desired finding count; no claim of operating an interface or observing humans. Output JSON maps packet ID to report text. Candidate wording is retained in variants.json; operational agent messages paraphrased those instructions without changing the requirements.

There was one generated report per condition/case, no sampling repeats or rewritten reports. This cannot separate instruction effects from generation variance. Root reviewed evidence and selected the preservation candidate before its fresh reports were generated. A separate agent independently adjudicated development reports without seeing selection or evaluator results. Fresh baseline was generated before selection, without any candidate context. The selected fresh generator received the exact preservation instruction.

Jev was accessed through the signed-in TypeSafe playground. Model selector was jev-latest; returned responses record jev-1.14.0. Four semantic batches maximum, no private user data, no experimental images. Questions judge report pairs holistically across four dimensions; separate dimension adjudication is recorded in the development review. Tie and neither are permitted. The reversal changes report order only; choice descriptions are unchanged. Copies of raw response JSON were obtained through the visible Copy response control. No API key was read or stored.
